# Music

Drop an mp3 here, then set its path in
`data/wedding.ts` under `audio.src` — for example `"/audio/wedding-ambient.mp3"`.
The music control then appears in the bottom-right corner once the invitation
is opened.

With no file present the control does not render at all — the invitation is
unaffected. It never autoplays; the guest has to press it.

Keep the file small (under ~2 MB) and loopable.
